# Characters

Locked master style references for recurring video characters. Each
character gets its own folder containing:

- A reference sheet image (full turnaround, expression set, pose set,
  costume detail close-ups) — the canonical visual source of truth.
- A `STYLE_GUIDE.md` transcribing identity, proportions, palette, locked
  pose/expression sets, and usage rules for generation.

Once a character folder is added here, treat it as locked: new shots should
be generated *from* the reference sheet and guide rather than redesigned
from scratch, and any approved additions (new poses, expressions, outfits)
get appended back into that character's `STYLE_GUIDE.md`.
